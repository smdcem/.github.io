# Chiemi Shimada — portfolio site

A static site rebuilding [sites.google.com/view/chiemi-shimada](https://sites.google.com/view/chiemi-shimada)
as plain HTML/CSS, ready to host for free on GitHub Pages. No build step,
no framework, no dependencies other than two Google Fonts loaded from a CDN.

## What's here

```
index.html              Home — hero + the project index ("the reel")
cv.html                 Full CV: exhibitions, screenings, awards, education, press
projects/*.html         One page per work (11 total)
css/style.css           The entire design system (colours, type, layout, motion)
images/                 Empty — see below
build.py                Optional: regenerates every HTML page from the data in it
```

`build.py` is not required to run the site — the HTML files it produced are
already sitting next to it. It's there so that if you'd rather edit structured
Python data than hand-edit HTML, you can: open `build.py`, change the text in
the `PROJECTS` or `CV` dictionaries, then run `python3 build.py` to regenerate
every page consistently. Either approach works; edit whichever you're more
comfortable with.

## 1. Add your banner image, project images, and video

The home page opens with a full-screen banner image (your name overlaid in
white, top-left) before the dark nav bar comes into view on scroll. Right now
that banner is a placeholder — open `index.html` and swap:

```html
<div class="hero-banner">
  <div class="placeholder-label">Banner image goes here<br>(images/banner.jpg)</div>
  <a class="hero-name" href="index.html">Chiemi Shimada</a>
</div>
```

for:

```html
<div class="hero-banner">
  <img src="images/banner.jpg" alt="">
  <a class="hero-name" href="index.html">Chiemi Shimada</a>
</div>
```

(remove the `placeholder-label` div, add an `<img>` pointing at your file in
`images/`). The banner is 92% of the viewport height by default — adjust
`.hero-banner`'s `height` in `css/style.css` if your image has different
proportions.

The original Google Sites pages also embed images and videos hosted on
Google's own servers, which can't be pulled onto another host automatically.
Each project page currently has placeholder boxes marked **"Image 1", "Image
2"** etc. — open the page's HTML and swap them for the real thing:

```html
<!-- placeholder -->
<div class="media-frame">Image 1</div>

<!-- replace with -->
<div class="media-frame"><img src="../images/kleroterion-01.jpg" alt="Still from Kleroterion"></div>
```

Drop your image files into the `images/` folder and point to them with a
relative path like above. For video, since your Vimeo account is already
linked from the site, embedding a Vimeo player is the easiest route:

```html
<div class="video-embed">
  <iframe src="https://player.vimeo.com/video/YOUR_VIDEO_ID"
          allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
</div>
```

One video is already wired up for real: the Celestial Palpitations
(Installation) page embeds the YouTube clip that was linked from the original
site. Use it as a working example.

## 2. Preview locally (optional)

Any static file server works. From this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## 3. Put it on GitHub

1. Create a new repository on GitHub — if it'll be your only site, name it
   `<your-username>.github.io`; otherwise any name works (e.g. `portfolio`).
2. From this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial site"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages** → under "Build and deployment", set
   **Source** to "Deploy from a branch", branch `main`, folder `/ (root)` →
   **Save**.
4. GitHub will publish the site at:
   - `https://<your-username>.github.io/` if the repo is named
     `<your-username>.github.io`, or
   - `https://<your-username>.github.io/<repo-name>/` otherwise.

It can take a minute or two for the first deploy to go live.

## 4. Custom domain (optional)

If you'd rather use your own domain: **Settings → Pages → Custom domain**,
enter the domain, and add the DNS records GitHub shows you (a `CNAME` record
pointing at `<your-username>.github.io` for a subdomain, or the four GitHub
`A` records for an apex domain). GitHub also offers free HTTPS for custom
domains once DNS propagates — tick "Enforce HTTPS" once it's available.

## Editing content

- **Text** — just edit the HTML directly (or the Python data, then
  `python3 build.py`).
- **Nav / project order** — the project order lives in three places that
  should stay in sync: `index.html`'s reel, the `PROJECTS` list order in
  `build.py`, and the Prev/Next links at the bottom of each project page
  (auto-generated by `build.py` from that same list order).
- **Colours and fonts** — all defined once as CSS custom properties at the
  top of `css/style.css` under `:root`.
